## 📌 Sobre o Projeto

O projeto foi desenvolvido para analisar padrões financeiros e prever possíveis casos de inadimplência, utilizando técnicas de Machine Learning aplicadas ao contexto bancário.

---

## 🧩 Engenharia de Dados

Criação da variável:

```python
income_commitment_ratio
```

Essa métrica representa o comprometimento da renda do cliente, auxiliando na identificação de perfis financeiros com maior risco de inadimplência.

- Tratamento e limpeza de dados

- Escalonamento para modelos lineares  
- Separação entre treino e teste

## 🤖 Modelagem Preditiva

Foram treinados e avaliados dois modelos de Machine Learning:

- Regressão Logística  
- Random Forest

## 🎯 Estratégia de Avaliação

O principal indicador analisado foi o **Recall**, priorizando a identificação do maior número possível de clientes com risco de inadimplência e reduzindo potenciais perdas financeiras para o Banco23.
